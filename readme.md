# AI Assisted Coding Assignment

## Student Assignment

This repository contains the Python programs developed for the AI Assisted Coding Assignment.

## Questions

### Q1 - Employee Salary
Python program using an Employee class to calculate bonus and total salary based on the basic salary.

### Q2 - Student Marks
Python program using loops and conditional statements to classify student marks as Distinction, Pass, or Fail.

### Q3 - Product Inventory
Python program using a Product class and loops to calculate total inventory value and identify low-stock products.

### Q4 - Electricity Bill
Python program using an ElectricityBill class to calculate electricity bills based on units consumed.
